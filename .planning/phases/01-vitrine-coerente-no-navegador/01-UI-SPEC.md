# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none |
| Icon library | none |
| Font | Inter (body and label), Bebas Neue (heading and display) |

Manual design system: the `:root` custom properties in `src/index.css` and the co-located CSS Modules under `src/components/`. `components.json` is absent. Do not initialize shadcn. Do not add Tailwind, MUI, or any component kit.

Styling stays CSS Modules (`styles` import, camelCase classes, `Active` suffix for the selected state). Global tokens stay in `src/index.css`. Do not add a shared `Header` component or a `src/components/ui/` folder. Each screen keeps its module.

Icons stay the glyphs already in the markup (`⟳`, `⬇`, `▲`, `▼`, `›`, `←`). Do not add an icon package. Every control keeps a visible text label. The logo button keeps `alt="Ford"`.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gaps inside the camera list and the component explorer |
| sm | 8px | Space between export buttons and between stacked phone actions |
| md | 16px | Default padding inside cards, panels, and the report header |
| lg | 24px | Home header padding, spec-grid padding, section padding |
| xl | 32px | Space between the home fact grid and the action row; hint offset from the bottom edge |
| 2xl | 48px | Home copy panel offset from the left edge |
| 3xl | 64px | Top offset of the specs camera column and the component explorer |

Exceptions: none

`src/index.css` does not define spacing tokens. This scale is the only spacing this phase may write when a rule is edited. Do not add a value outside this list. Breakpoints stay `700px`, then `500px`. This phase does not reflow the specs sheet.

## Typography

| Role | Size | Weight | Line Height | Face |
|------|------|--------|-------------|------|
| Body | 14px | 400 | 1.5 | `'Inter', sans-serif` |
| Label | 12px | 600 | 1.2 | `'Inter', sans-serif` |
| Heading | 20px | 400 | 1.2 | `'Bebas Neue', sans-serif` |
| Display | 96px | 400 | 1 | `'Bebas Neue', sans-serif` |

Exactly these four sizes and these two weights. Body line height 1.5 and label line height 1.2 are the researcher defaults (`src/index.css` sets the family only). Heading line height 1.2 matches `.panelTitle` in `src/components/SpecsPage.module.css`. Display line height 1 matches `.title` in `src/components/HeroUI.module.css`.

Size sources, already in the modules:

- Body 14px — home description (`.description`, `0.88rem`).
- Label 12px — loader status (`.text`) and the specs back button (`0.75rem`).
- Heading 20px — fact figures (`.specValue` and `.heroCardValue`, `1.3rem`).
- Display 96px — the home word “Ranger” (`.titleF`, `6rem`).

When a text rule is edited, set it to one of these four roles. Labels and buttons are uppercase Inter. Fact figures, screen titles, and the home name are Bebas Neue. The document font on `html` stays `'Inter', sans-serif`, with `-webkit-font-smoothing: antialiased`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#080a0e` | Page background, canvas shell, header scrim. Token `--bg`. |
| Secondary (30%) | `#0f1318` | Spec grid, chart cards, explorer rows, report tables. Token `--surface`. |
| Accent (10%) | `#f54b2e` | See the reserved list. Token `--accent`. |
| Destructive | none | This phase has no destructive action |

Supporting tokens already in `src/index.css`. They are not a second accent:

| Token | Value | Usage |
|-------|-------|-------|
| `--border` | `#1a2030` | Hairline around cards and the spec grid |
| `--text-primary` | `#e8e2d6` | Headings, fact figures, body on the dark shell |
| `--text-secondary` | `#5a6478` | Descriptions, inactive labels, footer meta |
| `--accent-glow` | `rgba(245, 75, 46, 0.3)` | Text shadow behind the home display word only |
| `--ford-blue` | `#003478` | Leave defined. Do not paint chrome with it |
| `--ford-silver` | `#b0bac8` | Leave defined. Do not paint chrome with it |

60% of each screen is `--bg`. 30% is `--surface` on the panels that sit over the canvas or the report column. 10% is `--accent`.

Accent reserved for:

- The filled primary button “Ver Specs” (fill `--accent`, label `--bg`)
- The word “Raptor” in the home title and the report hero title
- The home eyebrow and the report eyebrow
- The selected camera category, selected camera child, selected specs tab, selected feature tab, and the selected explorer row’s left border
- The loader progress fill
- The 2px leading rule on the home spec grid and the top rule on each report chart card
- The PDF export button’s border and label

Accent is not used for the logo, “Relatório”, “← Voltar”, CSV, TXT, body copy, or ordinary borders.

Replace a hardcoded hex with the matching variable when it equals a token: `#080a0e`, `#0f1318`, `#1a2030`, `#f54b2e`, `#e8e2d6`, `#5a6478`, and `rgba(245, 75, 46, 0.3)`. Secondary copy uses `--text-secondary` only. Do not add a custom property.

Score and competitor fills already in `src/components/ReportPage.jsx` (`SCREEN_COMPETITOR_COLORS`, `PRINT_COMPETITOR_COLORS`) and the grade classes in `src/components/ReportPage.module.css` stay data encoding for charts. They are not chrome accent. This phase does not add colors to that set. The Raptor series stays `--accent` (`#f54b2e`).

Primary button label is `--bg` on `--accent`. On hover the fill stays `--accent` and the button moves up 1px, as `.btnPrimary:hover` does now.

## Visual Hierarchy

Focal point on início: the display word “Ranger” (96px, `--text-primary`) over the vehicle, with “Raptor” in `--accent` on the next line. The filled “Ver Specs” button is the only solid action. The 3D vehicle is the ground, not a second headline.

Focal point on especificações: the vehicle in the canvas. `--accent` marks only the selected camera category and the selected spec tab.

Focal point on relatório: the hero title “RANGER RAPTOR”, with “RAPTOR” in `--accent`. Charts and the grade grid sit below that title.

No icon-only action. CSV, TXT, and PDF show those words. Chevrons sit beside a text label. The logo is a button with `alt="Ford"`.

## Screens and Interactions

This phase does not add a screen. Page state stays `'home' | 'specs' | 'report'` in `src/App.jsx`. One screen is mounted at a time.

| Screen | Files | What the person can do |
|--------|-------|------------------------|
| Início | `HeroUI.jsx`, `CarViewer.jsx`, `LoaderUI.jsx` | Wait for the loader, orbit the vehicle, read the four facts, choose “Ver Specs” or “Relatório” |
| Especificações | `SpecsPage.jsx` | Change camera, tab, and component. Open “Relatório”. “← Voltar” returns to início. The logo returns to início |
| Relatório | `ReportPage.jsx` | Read the same facts, competitors, and scores. Export CSV, TXT, or print via PDF. “← Voltar” returns to especificações. The logo returns to início |

Header on início, after this phase: the Ford logo only. The four dead links are gone. “Ver Specs” and “Relatório” stay in the left panel, not in the header.

Header on especificações: logo, “← Voltar”, the screen title, “Relatório”.

Header on relatório: logo, eyebrow, “Relatório Comparativo”, CSV, TXT, PDF, “← Voltar”.

Keyboard focus uses a 1px `--accent` outline on buttons and the logo. That outline is a researcher default; the modules do not style `:focus` today.
